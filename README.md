## ✨ Features

- 🤖 **AI Powered** — Groq Llama 3.3 — fast, accurate, free
- 💬 **Any Topic** — SQL, banking, coding, maths, writing, general knowledge
- 🗄️ **SQL & Oracle** — Finacle CBS schema, PL/SQL queries
- 🏦 **Banking** — RBI guidelines, NPA classification, NABARD rules
- 🧮 **Calculations** — EMI, interest, tax in Indian format (₹, lakhs, crores)
- 💻 **Coding** — Python, JavaScript, Shell scripting, any language
- 📋 **Copy Response** — Copy any AI reply with one tap
- 🕐 **Recent Chats** — Access your previous conversations
- ✉️ **Email Writer** — Quick link to Vicky's Email Writer app
- 🔄 **Auto Updates** — App updates automatically — no reinstall needed
- 🌙 **Dark Theme** — Beautiful dark green UI

## 🚀 How to Install

1. Download the APK from the link above
2. Open the downloaded file on your Android phone
3. Tap **"Install"**
4. If asked, allow **"Install from unknown sources"**
5. Open **AskVicky** and start asking! ✅
